# 🚩 FLAGIT — HSE Observation Platform

FLAGIT is a lightweight web-based Health, Safety & Environment (HSE) observation platform designed for site teams to quickly raise, track, and close safety observations.

---

## 🔧 Features

* User authentication (Sign up / Sign in)
* Raise HSE observations (“Flag it”)
* Assign actions and track status
* Upload observation photos
* AI-assisted recommendations (optional)
* Dashboard with safety metrics
* NCR (Non-Conformance Report) tracking
* Observation close-out with evidence

---

## 🏗️ Use Case

Designed for:

* Construction sites
* Event build-up & breakdown operations
* Industrial and oil & gas environments

Helps safety teams:

* Capture hazards instantly
* Improve reporting consistency
* Track corrective actions
* Maintain audit-ready records

---

## 🚀 How to Use

1. Open the HTML file in your browser
2. Click **Create one** to sign up
3. Enter your details (including organisation name)
4. Verify using the generated code
5. Start raising observations
